# Introduction

## About This Document

This document provides a complete guide for installing Python on your computer. Python is one of the most popular programming languages in the world, widely used for web development, data science, automation, artificial intelligence, and general-purpose scripting. Whether you are a student, developer, or hobbyist, having Python correctly installed on your system is the first step toward writing and running Python programs.

This guide is intended for beginners as well as users who want a quick reference for setting up Python on **Windows**, **macOS**, or **Linux**.

## Purpose

The purpose of this document is to:

- Explain what is required before installing Python
- Walk through the installation process step by step
- Show how to verify that the installation was successful
- Provide solutions to common installation problems
- Answer frequently asked questions about Python installation

## Who Should Use This Guide

- First-time programmers setting up their development environment
- Students installing Python for coursework or projects
- Professionals setting up a new machine or environment
- Anyone who needs a reliable reference for troubleshooting installation issues

# Software Requirements

Before installing Python, ensure your system meets the following requirements.

## Operating System Support

| Operating System | Supported Versions |
|-------------------|--------------------|
| Windows | Windows 10, Windows 11 |
| macOS | macOS 11 (Big Sur) and later |
| Linux | Most modern distributions (Ubuntu 20.04+, Fedora, Debian, etc.) |

## Hardware Requirements

- **Processor:** Any modern 64-bit processor
- **RAM:** Minimum 2 GB (4 GB or more recommended)
- **Disk Space:** At least 100 MB of free space for a basic installation

## Prerequisites

- Administrator or root access to install software
- A stable internet connection to download the installer
- A web browser to access the official Python website
- (Optional) A code editor such as **VS Code**, **PyCharm**, or **Sublime Text**

## Recommended Python Version

It is recommended to install the **latest stable release of Python 3**, as Python 2 has reached end-of-life and is no longer maintained or supported.

You can check the latest available version at the official website: [https://www.python.org/downloads/](https://www.python.org/downloads/)
