# Contributing to the Student Project

Thank you for contributing to this Python student project.

## 1. How to Report an Issue

1. Describe the problem clearly.
2. Explain what you expected to happen.
3. Provide the actual result.
4. Give the steps to reproduce the problem.

## 2. How to Suggest a Feature

1. Describe the feature.
2. Explain why it would be useful.
3. Give a simple example of how it could work.

## 3. How to Create a Branch

Create a new branch for your changes.

```text
git checkout -b feature-name
```

Use a short and meaningful branch name.

## 4. How to Make Changes

1. Create a branch.
2. Make the required changes.
3. Keep the changes simple and clear.
4. Save your work.

## 5. How to Test Changes

1. Run the Python program.
2. Check the output.
3. Test different inputs.
4. Make sure the program works as expected.

## 6. How to Create a Pull Request

1. Push your branch.
2. Create a pull request.
3. Explain what you changed.
4. Mention any important testing done.
5. Submit the pull request for review.

## 7. Basic Coding Guidelines

- Write simple and readable Python code.
- Use meaningful names for variables.
- Keep the code organized.
- Avoid unnecessary code.
- Test your changes before submitting them.
